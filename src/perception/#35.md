# How to close issue `#35`

No code. Run these, then commit the `.onnx` files.

**On a workstation with `ultralytics`:**

```bash
yolo export model=models/best.pt   format=onnx imgsz=640 nms=False
yolo export model=models/medium.pt format=onnx imgsz=640 nms=False
```

**On the Jetson:**

```bash
./build.sh --engines
```

**Verify the output layout** before writing any decode code:

```bash
python -c "import onnx; m = onnx.load('models/best.onnx'); print([d.dim_value for d in m.graph.output[0].type.tensor_type.shape.dim])"
```

Expected: `[1, 10, 8400]` for 6 classes (`4 + 6 = 10` rows, 8400 anchors). If it prints `[1, 8400, 10]`, the output is transposed and `Yolo::detect()` must be adjusted - the code below assumes `[1, rows, anchors]`.

**Closes #35** when both `.engine` files exist and the layout is confirmed.
