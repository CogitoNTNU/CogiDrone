# Ground-clutter props: sources and licences

Everything in this folder can be redistributed in a public repository. All third-party
sources are **CC0 1.0 (public domain)**, so attribution is not legally required. It is given
here anyway, as a courtesy and so the assets can be traced. The procedural parts are
original work for this project and are also released as CC0.

The meshes were decimated, converted to Z-up, re-centred and packed into texture atlases
by `sim/tools/props/build_assets.py`. Textures were resized and some were colour-graded.
