# Tree assets: sources and licences

Everything in `sim/assets/trees/` is generated by `sim/tools/trees/` (see the README there).
The tree meshes are procedural (our own code, same licence as this repository). The textures
are built from the CC0 images below. CC0 needs no attribution, but we list the sources anyway
so the assets can be traced and rebuilt.

| Used for | Source asset | Files used | Author | Licence | URL |
|---|---|---|---|---|---|

| Scots pine needle tufts, pine lower bark | Poly Haven "Pine Tree 01" | `twig_diff` 2k, `twig_alpha` 2k, `bark_diff` 1k | Rob Tuytel (photography), Rico Cilliers (modelling) | CC0 1.0 | https://polyhaven.com/a/pine_tree_01 |
| Birch leaves | Poly Haven "Tree Small 02" | `leaves_diff` 2k, `leaves_alpha` 2k | Rico Cilliers | CC0 1.0 | https://polyhaven.com/a/tree_small_02 |

The birch bark (white with lenticels), all colour grading, the sprite compositions (branch
sprays, tufts, leaf clusters), the far-tier impostor atlas (`far.png`, rendered from our own
meshes) and all meshes are original work produced by the scripts in `sim/tools/trees/`.

Poly Haven licence: https://polyhaven.com/license (CC0). ambientCG licence: https://docs.ambientcg.com/license/ (CC0).

No Sketchfab, Megascans/Fab, BlenderKit or Xfrog content is used.
